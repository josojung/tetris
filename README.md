# 테트리스 캐비닛

의존성 없는 단일 HTML 파일 테트리스. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 좌우 이동 |
| `↓` | 소프트 드롭 |
| `Space` | 하드 드롭 |
| `↑` / `X` | 시계 방향 회전 |
| `Z` | 반시계 방향 회전 |
| `C` | 홀드 |
| `P` | 일시정지 |
| `R` | 새 게임 |

모바일에서는 화면 하단 터치 패드로 조작합니다.

## 규칙

- 10 × 20 보드, 7-백(7-bag) 랜덤 생성기
- 회전 시 벽 차기(wall kick) 보정: 0, ∓1, ∓2칸
- 고스트 피스로 낙하 지점 표시, 다음 블록 3개 미리보기 + 홀드 1칸
- 점수: 1/2/3/4줄 클리어 = 100/300/500/800 × 레벨, 소프트 드롭 1점/칸, 하드 드롭 2점/칸
- 10줄마다 레벨업, 레벨당 낙하 간격 85ms 감소 (최소 90ms)

## 배포

GitHub Pages로 바로 서비스할 수 있습니다: 저장소 Settings → Pages → Source를 `main` 브랜치 루트로 지정.
